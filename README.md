# Atividade de Branches
Nessa atividade de GCSI, irei implementar conteúdos aprendidos na disciplina de Padrões de Projeto. 
O escopo será um serviço de aluguel de imóveis, como AirBnB.

# Instalações Necessárias
Ao baixar a pasta do projeto, abrí-la no CMD ou Terminal equivalente e executar:

npm init -y

npm install -D typescript tsx

Para executar o projeto: npx tsx src/index.ts
